# GreenNest-Online-Nursery-Gardening-Services-Platform
 GreenNest is an eco-commerce and on-demand gardening services platform built to make urban plant parenthood effortless. Developed with React 19, Vite,   Tailwind CSS v4, Lucide Icons, and Framer Motion, it bridges urban homeowners with local nurseries (like Urbano Nursery) and verified gardening   professionals.
